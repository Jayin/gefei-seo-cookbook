# 使用指南

本指南介绍如何使用 Google SEO 实战教程。

## 快速开始

### 1. 安装依赖

```bash
cd seo-book
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:5173 查看效果。

### 3. 构建生产版本

```bash
npm run build
```

### 4. 预览生产版本

```bash
npm run preview
```

访问 http://localhost:4173 预览生产版本。

## 常见问题

### Q: 学习 SEO 需要多长时间？

A: 取决于你的基础和学习时间。通常需要 3-6 个月才能看到明显效果。

### Q: SEO 还有效吗？

A: 有效。SEO 仍然是获取免费流量的最有效方式之一。

### Q: 需要学习编程吗？

A: 不需要，但了解基本的 HTML 和 CSS 会有帮助。

### Q: 如何开始学习 SEO？

A: 从入门指南开始，逐步学习各个模块，结合实践操作。

### Q: 需要购买付费工具吗？

A: 初学者可以使用免费工具。随着需求增长，可以考虑付费工具。

### Q: SEO 和 SEM 有什么区别？

A: SEO 是搜索引擎优化，通过优化网站获取免费流量。SEM 是搜索引擎营销，通过付费广告获取流量。

## 技术支持

### 本地开发问题

1. 确保 Node.js 版本 >= 16
2. 确保 npm 版本 >= 7
3. 删除 `node_modules` 目录，重新安装依赖
4. 检查网络连接

### 构建问题

1. 检查 Markdown 文件语法
2. 检查 HTML 标签是否正确闭合
3. 检查链接是否有效
4. 查看错误信息，定位问题

### 内容问题

1. 检查内容是否准确
2. 检查链接是否有效
3. 检查图片是否显示
4. 检查格式是否正确
