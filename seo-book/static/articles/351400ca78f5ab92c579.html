案例演示：如何分析关键词，如何对比网站，如何推断排前面的网站能够拿到排名的原因 大家好，我是哥飞。

今天给大家分享前几天哥飞在社群里的一次小课堂。

哥飞社群里时不时有小课堂分享，这是上周日的一次分享，会用一个实际案例来说明如何分析关键词，如何对比网站，如何推断排前面的网站能够拿到排名的原因。

我们先看两个网站，blockblastsolver.com 注册于2024年9月1日，blockblastsolver.org 注册于2024年10月7日。

前者只有43个外链域名，DR20，后者有145个外链域名，DR21。

但是前者1月访问量230万，而后者1月访问量1.3万。

谷歌搜索 block blast solver 可以看到，已经有 Sitelinks了，也就是说，谷歌已经认定，用户搜索这个词，就是想找这个站。

所以只要 .com 域名这个站不犯错误，后面别的站很难超过他了。

.com 站能够拿到第一名，除了先发优势之外，他的行为数据也是全面超过 .org 站的。

通过谷歌趋势，看 block blast 和 block blast solver 的数据可以发现，block blast solver 开始有热度，是在9月21日之后，准确的说，是9月27日。

而通过archive.org 可以查到，.com 站在9月2日就上线了第一版了。

https://web.archive.org/web/20240902135107/http://www.blockblastsolver.com/block blast solver 的搜索热度怎么来的呢？

在 Reddit 可以看到作者在9月25日发的一个帖子，火了。

10月份，作者也开通了 Tiktok 账号，发布了多个视频，都获得了很不错的播放量。

由此我们得出结论，blockblastsolver.com 站长在发现 block blast 火了之后，根据经验判断出有 solver 需求，于是注册域名，做了网站，然后到处推广，把 block blast solver 词给推起来了，让大家知道有这个 solver 网站。

而那个时候，谷歌早就收录了 blockblastsolver.com ，自然而然，谷歌就认为，block blast solver 就是 blockblastsolver.com 的品牌词，于是给了第一名。

之后又因为能够持续不断的满足搜索用户的需求，于是Sitelinks也给安排上了。

从上面的网站流量曲线也可以看到，9月几乎没有流量，到了10月就有122万访问量了，之后几个月流量分别是198万、378万、226万。

为什么后面流量会下降呢？

从谷歌趋势看到，是游戏本身的热度下降了导致的。

以上，就是今晚的#哥飞小课堂 ，用一个实际案例，给大家演示了，如何分析一个关键词，如何对比多个网站，如何推断为什么排前面的网站能够拿到排名。

类似的小课堂教学，在社群配套网站上，已经有100个了。
