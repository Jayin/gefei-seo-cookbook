版本说明 ​

版本号格式 ​

版本号格式：主版本号.次版本号.修订号

  • 主版本号： 当你做了不兼容的 API 修改
  • 次版本号： 当你做了向下兼容的功能性新增
  • 修订号： 当你做了向下兼容的问题修正

更新类型 ​

  • 新增： 新功能
  • 变更： 对现有功能的变更
  • 修复： 问题修复
  • 移除： 移除的功能

更新频率 ​

  • 主版本号： 每年 1-2 次
  • 次版本号： 每月 1-2 次
  • 修订号： 根据需要随时发布

如何更新 ​

  1. 查看更新日志，了解变更内容
  2. 备份现有内容
  3. 拉取最新代码
  4. 安装依赖更新
  5. 测试功能是否正常
  6. 部署更新

向后兼容性 ​

  • 主版本号： 不保证向后兼容
  • 次版本号： 保证向后兼容
  • 修订号： 保证向后兼容

废弃功能 ​

废弃的功能会在更新日志中标记，并在后续版本中移除。

已知问题 ​

已知问题会在更新日志中标记，并在后续版本中修复。
