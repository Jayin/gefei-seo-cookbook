04-页面 SEO 优化 ​

页面 SEO（On-Page SEO）是指优化网页内部元素，使搜索引擎能够更好地理解页面内容，从而获得更好的排名。

一、TDH 优化 ​

TDH 是页面 SEO 的三大核心元素：

1. Title（页面标题） ​

Title 是告诉搜索引擎页面主题的最重要元素。

最佳实践：

  • 每个页面有唯一的 Title
  • 长度控制在 50-60 个字符
  • 将重要关键词放在前面
  • 在结尾加上品牌名称
  • 为用户编写，而不是为搜索引擎

示例：

html
<!-- 好的 Title -->
<title>Google SEO 入门教程 - 从零开始学习搜索引擎优化 | SEO Book</title>

<!-- 不好的 Title -->
<title>SEO, SEO教程, SEO优化, SEO入门, SEO技巧</title>

2. Description（页面描述） ​

Description 不是排名因素，但会影响点击率。

最佳实践：

  • 每个页面有唯一的 Description
  • 长度控制在 150-160 个字符
  • 包含主要关键词
  • 使用自然的句子
  • 包含号召行动（CTA）

示例：

html
<meta name="description" content="学习 Google SEO 优化的基础知识，包括关键词研究、页面优化、技术 SEO 等内容。适合 SEO 初学者的完整教程。">

3. Headings（标题标签） ​

Headings 是页面内容的骨架结构。

最佳实践：

  • H1：每个页面只有一个，包含主要关键词
  • H2：主要章节标题
  • H3：子章节标题
  • 保持层级结构清晰
  • 为用户阅读而写

示例：

html
<h1>Google SEO 入门教程</h1>
<h2>什么是 SEO？</h2>
<h3>为什么 SEO 很重要？</h3>
<h3>SEO 的核心要素</h3>
<h2>关键词研究</h2>
<h3>如何找到关键词</h3>

提示

Title 和 H1 可以相同，也可以不同。如果写不出不同的 H1，让它们相同也可以。

二、内容优化 ​

1. 内容质量 ​

高质量内容的特征：

  • 原创性：不要抄袭或复制内容
  • 深度：全面深入地讲解主题
  • 实用性：对用户有实际帮助
  • 可读性：结构清晰，易于阅读

2. 内容长度 ​

  • 没有固定的最佳长度
  • 内容应该足够覆盖主题
  • 长内容通常排名更好
  • 但不要为了长度而注水

3. 关键词使用 ​

自然使用关键词：

  • 在 Title 和 H1 中使用
  • 在第一段中使用
  • 在正文中自然出现
  • 在结尾总结中使用

避免关键词堆砌：

  • 关键词密度保持 1-2%
  • 使用语义相关的词
  • 为用户写作，而不是为搜索引擎

4. 内容结构 ​

使用小标题：

  • 帮助用户快速浏览
  • 帮助搜索引擎理解结构
  • 提高内容可读性

使用列表：

  • 项目符号列表
  • 编号列表
  • 让内容更易读

使用表格：

  • 展示对比信息
  • 展示结构化数据

三、图片优化 ​

1. 文件名 ​

使用描述性的文件名：

<!-- 好的文件名 -->
google-seo-tutorial.webp

<!-- 不好的文件名 -->
IMG_1234.jpg

2. Alt 属性 ​

Alt 属性是图片的文字描述：

html
<img src="seo-workflow.webp" alt="SEO 优化工作流程图">

最佳实践：

  • 准确描述图片内容
  • 包含相关关键词
  • 保持简洁
  • 避免关键词堆砌

3. 图片压缩 ​

  • 使用工具压缩图片
  • 选择合适的格式（WebP 优先）
  • 控制图片尺寸
  • 使用懒加载

4. 图片尺寸 ​

  • 根据显示需求设置尺寸
  • 避免使用过大的图片
  • 使用响应式图片

四、内部链接 ​

1. 什么是内部链接？ ​

内部链接是同一网站内页面之间的链接。

2. 内部链接的作用 ​

  • 帮助搜索引擎发现页面
  • 传递页面权重
  • 提升用户体验
  • 降低跳出率

3. 内部链接最佳实践 ​

使用描述性锚文本：

html
<!-- 好的锚文本 -->
<a href="/guide/keyword-research">学习关键词研究方法</a>

<!-- 不好的锚文本 -->
<a href="/guide/keyword-research">点击这里</a>

链接到相关页面：

  • 内容相关的页面互相链接
  • 新页面在首页有链接
  • 重要页面获得更多内链

保持合理的链接数量：

  • 每个页面 3-5 个内部链接
  • 避免过多的链接
  • 确保链接有价值

4. 内链结构 ​

首页 → 分类页 → 内容页

  • 清晰的层级结构
  • 任何页面 3 次点击内到达
  • 使用面包屑导航

五、URL 优化 ​

1. URL 结构 ​

好的 URL：

https://example.com/guide/keyword-research

不好的 URL：

https://example.com/index.php?id=123&cat=456

2. URL 最佳实践 ​

  • 使用小写字母
  • 使用连字符分隔单词
  • 保持简短
  • 包含关键词
  • 避免特殊字符

六、移动端优化 ​

1. 响应式设计 ​

  • 使用响应式布局
  • 确保文字可读
  • 按钮大小适合点击
  • 避免水平滚动

2. 移动端检查 ​

使用 Google 的移动设备适合性测试：

  • https://search.google.com/test/mobile-friendly

七、页面速度优化 ​

1. 图片优化 ​

  • 压缩图片
  • 使用 WebP 格式
  • 使用懒加载

2. 代码优化 ​

  • 压缩 CSS 和 JavaScript
  • 减少 HTTP 请求
  • 使用浏览器缓存

3. 服务器优化 ​

  • 使用 CDN
  • 启用 Gzip 压缩
  • 选择好的主机

八、页面 SEO 检查清单 ​

Title 检查 ​

  • [ ] 每个页面有唯一的 Title
  • [ ] Title 包含主要关键词
  • [ ] Title 长度在 50-60 字符
  • [ ] Title 包含品牌名称

Description 检查 ​

  • [ ] 每个页面有唯一的 Description
  • [ ] Description 包含关键词
  • [ ] Description 长度在 150-160 字符
  • [ ] Description 有号召行动

Headings 检查 ​

  • [ ] 每个页面有 H1 标签
  • [ ] H1 包含主要关键词
  • [ ] Headings 层级结构清晰
  • [ ] Headings 为用户而写

内容检查 ​

  • [ ] 内容是原创的
  • [ ] 内容有深度和价值
  • [ ] 关键词使用自然
  • [ ] 内容结构清晰

图片检查 ​

  • [ ] 图片有描述性文件名
  • [ ] 图片有 Alt 属性
  • [ ] 图片已压缩
  • [ ] 图片尺寸合适

链接检查 ​

  • [ ] 有合理的内部链接
  • [ ] 锚文本描述性
  • [ ] 链接到相关页面
  • [ ] 没有死链接

注意

页面 SEO 是基础，但不是全部。还需要结合技术 SEO 和外链建设，才能获得好的排名。
