05-Google Analytics ​

Google Analytics（GA）是 Google 提供的免费网站分析工具，帮助你了解网站流量、用户行为和转化效果。

一、为什么使用 GA？ ​

1. 核心功能 ​

  • 跟踪网站流量
  • 分析用户行为
  • 监控转化效果
  • 生成详细报告

2. 为什么重要？ ​

  • 了解用户：知道用户是谁，从哪里来
  • 分析行为：了解用户在网站上的行为
  • 评估效果：评估营销活动的效果
  • 优化决策：基于数据做出优化决策

二、设置和安装 ​

1. 创建 GA 账号 ​

  1. 访问 https://analytics.google.com
  2. 使用 Google 账号登录
  3. 点击"开始衡量"
  4. 填写账号信息
  5. 创建媒体资源

2. 安装跟踪代码 ​

获取跟踪代码：

  1. 在 GA 中选择媒体资源
  2. 点击"数据流"
  3. 选择网站
  4. 复制跟踪代码

安装代码： 将跟踪代码添加到网站所有页面的 &lt;head&gt; 中：

html
<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=GA_MEASUREMENT_ID"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'GA_MEASUREMENT_ID');
</script>

3. 验证安装 ​

方法：

  1. 在 GA 中查看实时报告
  2. 访问你的网站
  3. 确认访问被记录

三、核心概念 ​

1. 用户（Users） ​

  • 访问网站的独立用户
  • 基于 Cookie 识别
  • 新用户 vs 回访用户

2. 会话（Sessions） ​

  • 用户在网站上的一次访问
  • 30 分钟不活动后结束
  • 包含多个页面浏览

3. 页面浏览（Pageviews） ​

  • 页面被浏览的次数
  • 同一页面多次浏览会重复计算

4. 跳出率（Bounce Rate） ​

  • 只浏览一个页面就离开的会话比例
  • 越低越好
  • 反映内容质量和用户体验

5. 平均会话时长 ​

  • 用户在网站上的平均停留时间
  • 越长越好
  • 反映内容吸引力

四、核心报告 ​

1. 实时报告 ​

访问路径： 实时 > 概览

功能：

  • 查看当前在线用户
  • 查看实时流量来源
  • 查看实时页面浏览
  • 查看实时事件

使用场景：

  • 验证跟踪代码
  • 监控营销活动
  • 查看实时效果

2. 用户获取报告 ​

访问路径： 获取 > 用户获取

关键指标：

  • 用户数量
  • 新用户数量
  • 会话数量
  • 跳出率

流量来源分类：

  • 自然搜索：来自搜索引擎的免费流量
  • 直接流量：直接输入网址或使用书签
  • 引荐流量：来自其他网站的链接
  • 社交流量：来自社交媒体
  • 付费搜索：来自付费广告

使用方法：

  1. 分析流量来源
  2. 找出高质量来源
  3. 优化营销策略

3. 用户行为报告 ​

访问路径： 行为 > 网站内容 > 所有页面

关键指标：

  • 页面浏览量
  • 唯一页面浏览量
  • 平均停留时间
  • 跳出率
  • 退出率

使用方法：

  1. 找出热门页面
  2. 分析用户行为
  3. 优化页面内容
  4. 提升用户体验

4. 转化报告 ​

访问路径： 转化 > 目标

功能：

  • 设置目标
  • 跟踪转化
  • 分析转化路径
  • 评估转化效果

目标类型：

  • 目标网址
  • 时长
  • 页面/会话
  • 事件

使用方法：

  1. 设置目标
  2. 跟踪转化
  3. 分析转化路径
  4. 优化转化率

六、高级功能 ​

1. 事件跟踪 ​

什么是事件？

  • 用户与网站的互动
  • 不涉及页面加载
  • 可自定义跟踪

常见事件：

  • 按钮点击
  • 文件下载
  • 视频播放
  • 表单提交

设置方法：

javascript
gtag('event', 'click', {
  'event_category': 'button',
  'event_label': 'signup',
  'value': 1
});

2. 自定义报告 ​

功能：

  • 创建自定义报告
  • 选择指标和维度
  • 设置过滤器
  • 定期发送报告

使用方法：

  1. 点击"自定义"
  2. 选择"自定义报告"
  3. 设置指标和维度
  4. 保存并查看

3. 细分分析 ​

什么是细分？

  • 用户的子集
  • 基于特定条件
  • 用于深入分析

常见细分：

  • 新用户 vs 回访用户
  • 移动端 vs 桌面端
  • 不同流量来源
  • 不同地区

使用方法：

  1. 在报告中点击"添加细分"
  2. 选择或创建细分
  3. 分析细分数据

4. 归因模型 ​

什么是归因？

  • 分配转化功劳
  • 了解营销效果
  • 优化营销策略

归因模型：

  • 最终点击
  • 首次点击
  • 线性归因
  • 时间衰减

使用方法：

  1. 在转化报告中选择归因模型
  2. 比较不同模型
  3. 了解营销效果

七、GA 与 SEO ​

1. 监控 SEO 效果 ​

关键指标：

  • 自然搜索流量
  • 关键词排名
  • 着陆页表现
  • 转化率

分析方法：

  1. 查看自然搜索流量趋势
  2. 分析热门关键词
  3. 优化着陆页
  4. 提升转化率

2. 发现 SEO 机会 ​

方法：

  1. 找出高流量低转化页面
  2. 找出高跳出率页面
  3. 分析用户行为
  4. 制定优化策略

3. 评估 SEO 投资回报 ​

计算方法：

SEO 投资回报 = (SEO 带来的收入 - SEO 成本) / SEO 成本

需要数据：

  • 自然搜索流量
  • 转化率
  • 平均订单价值
  • SEO 成本

八、常见问题 ​

Q: GA 数据延迟多久？ ​

A: 通常延迟 24-48 小时。实时报告可以查看当前数据。

Q: 为什么 GA 和 GSC 数据不同？ ​

A: 两个工具的统计方式不同。GSC 统计搜索展示和点击，GA 统计网站访问。

Q: 如何提高数据准确性？ ​

A: 确保跟踪代码正确安装，过滤内部流量，设置正确的域名。

Q: GA 和 GA4 有什么区别？ ​

A: GA4 是最新版本，使用事件驱动模型，更注重用户隐私。建议使用 GA4。

十、实战案例 ​

案例：使用 GA 优化 SEO 策略 ​

背景：

  • 网站流量增长缓慢
  • 转化率低
  • 需要找出问题

步骤：

  1. 分析流量来源

    • 发现自然搜索流量占比低
    • 发现某些关键词流量高但转化低
    • 发现某些页面跳出率高

  2. 分析用户行为

    • 发现用户停留时间短
    • 发现用户浏览页面少
    • 发现用户流失点多

  3. 分析转化路径

    • 发现转化路径长
    • 发现某些环节流失严重
    • 发现转化率低

  4. 制定优化策略

    • 优化关键词策略
    • 优化页面内容
    • 优化转化路径
    • 提升用户体验

  5. 实施优化

    • 更新内容
    • 优化页面
    • 简化流程
    • 监控效果

结果：

  • 自然搜索流量增长 50%
  • 转化率提升 30%
  • 用户停留时间增加
