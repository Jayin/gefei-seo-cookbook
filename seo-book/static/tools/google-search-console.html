02-Google Search Console ​

Google Search Console（GSC）是 Google 提供的免费工具，帮助你监控和维护网站在 Google 搜索结果中的表现。

一、为什么使用 GSC？ ​

1. 核心功能 ​

  • 监控网站在 Google 搜索结果中的表现
  • 查看索引状态
  • 提交 Sitemap
  • 查看抓取错误
  • 监控核心网页指标

2. 为什么重要？ ​

  • 官方数据：来自 Google 的第一手数据
  • 免费使用：完全免费
  • 发现问题：及时发现技术问题
  • 优化依据：提供优化建议

二、设置和验证 ​

1. 添加网站 ​

  1. 访问 https://search.google.com/search-console
  2. 点击"添加属性"
  3. 选择属性类型（域名或网址前缀）
  4. 输入网站 URL

2. 验证网站所有权 ​

方法 1：HTML 文件

  1. 下载验证文件
  2. 上传到网站根目录
  3. 点击验证

方法 2：HTML 标签

  1. 复制 meta 标签
  2. 添加到网站首页的 &lt;head&gt; 中
  3. 点击验证

方法 3：Google Analytics

  1. 如果已安装 Google Analytics
  2. 使用相同账号验证

方法 4：Google Tag Manager

  1. 如果已使用 GTM
  2. 使用相同账号验证

3. 验证成功 ​

验证成功后，你将看到 GSC 控制面板。

三、核心功能 ​

1. 搜索结果报告 ​

访问路径： 搜索结果 > 搜索结果

关键指标：

  • 点击次数：用户点击你网站的次数
  • 展示次数：你的网站在搜索结果中展示的次数
  • 点击率（CTR）：点击次数 / 展示次数
  • 平均排名：你的网站在搜索结果中的平均位置

使用方法：

  1. 查看整体趋势
  2. 分析热门查询
  3. 分析热门页面
  4. 比较时间段

优化建议：

  • 找出高展示低点击的查询，优化标题和描述
  • 找出排名靠前的页面，进一步优化
  • 找出流量下降的原因

2. 网页索引报告 ​

访问路径： 索引 > 网页

关键指标：

  • 已编入索引：已被 Google 索引的页面
  • 未编入索引：未被 Google 索引的页面
  • 错误：导致无法索引的错误

常见问题：

  • 被 noindex 标签排除
  • 被 robots.txt 阻止
  • 重定向问题
  • 服务器错误
  • 软 404

使用方法：

  1. 查看索引覆盖率
  2. 分析未索引页面
  3. 修复索引问题
  4. 监控变化趋势

3. Sitemap 报告 ​

访问路径： 索引 > Sitemap

功能：

  • 提交 Sitemap
  • 查看 Sitemap 状态
  • 查看已提交的 URL 数量
  • 查看已索引的 URL 数量

使用方法：

  1. 提交 Sitemap URL
  2. 查看处理状态
  3. 查看错误信息
  4. 定期更新 Sitemap

最佳实践：

  • 只包含规范页面
  • 及时更新 Sitemap
  • 保持文件大小合理
  • 定期检查状态

4. 链接报告 ​

访问路径： 链接

报告类型：

  • 外部链接：其他网站指向你网站的链接
  • 内部链接：你网站内部的链接

关键指标：

  • 链接数量
  • 热门链接页面
  • 热门链接来源
  • 锚文本分布

使用方法：

  1. 分析外链质量
  2. 找出热门链接页面
  3. 监控链接增长
  4. 发现潜在问题

5. 核心网页指标 ​

访问路径： 体验 > 核心网页指标

指标类型：

  • LCP（最大内容绘制）：加载性能
  • FID（首次输入延迟）：交互性
  • CLS（累积布局偏移）：视觉稳定性

状态分类：

  • 良好
  • 需改进
  • 不达标

使用方法：

  1. 查看整体状态
  2. 分析问题页面
  3. 按照建议优化
  4. 监控改进效果

6. 移动设备易用性 ​

访问路径： 体验 > 移动设备易用性

检查内容：

  • 文字太小，难以阅读
  • 可点击元素太近
  • 内容超出屏幕
  • 视口未设置

使用方法：

  1. 查看问题页面
  2. 按照建议修复
  3. 验证修复
  4. 监控状态

四、高级功能 ​

1. URL 检查 ​

功能：

  • 检查特定 URL 的索引状态
  • 查看抓取信息
  • 请求编入索引
  • 查看渲染结果

使用方法：

  1. 输入 URL
  2. 查看索引状态
  3. 查看抓取信息
  4. 请求编入索引

适用场景：

  • 新页面索引
  • 页面问题诊断
  • 索引状态检查

2. 覆盖率报告 ​

功能：

  • 查看所有页面的索引状态
  • 分析索引错误
  • 监控索引趋势

使用方法：

  1. 查看错误类型
  2. 分析问题页面
  3. 按照建议修复
  4. 监控改进效果

3. 手动操作 ​

功能：

  • 查看手动惩罚
  • 了解惩罚原因
  • 提交重新审核

使用方法：

  1. 定期检查
  2. 了解惩罚原因
  3. 修复问题
  4. 提交重新审核

五、常见问题处理 ​

1. 页面未被索引 ​

检查步骤：

  1. 使用 URL 检查工具
  2. 查看索引状态
  3. 检查 robots.txt
  4. 检查 noindex 标签
  5. 检查 canonical 标签

解决方法：

  • 修复技术问题
  • 请求编入索引
  • 优化内容质量

2. Sitemap 错误 ​

常见错误：

  • Sitemap 无法访问
  • URL 错误
  • 格式错误

解决方法：

  • 检查 Sitemap URL
  • 验证 Sitemap 格式
  • 重新提交 Sitemap

3. 抓取错误 ​

常见错误：

  • 服务器错误（5xx）
  • 404 错误
  • 重定向问题

解决方法：

  • 修复服务器问题
  • 修复或重定向 404 页面
  • 优化重定向链

4. 移动设备问题 ​

常见问题：

  • 文字太小
  • 可点击元素太近
  • 内容超出屏幕

解决方法：

  • 优化字体大小
  • 调整元素间距
  • 使用响应式设计

六、最佳实践 ​

1. 定期检查 ​

建议频率：

  • 每周查看搜索结果报告
  • 每月查看索引报告
  • 每季度进行全面检查

2. 及时处理问题 ​

优先级：

  1. 手动惩罚（立即处理）
  2. 索引错误（尽快处理）
  3. 抓取错误（定期处理）
  4. 体验问题（持续优化）

3. 数据分析 ​

分析内容：

  • 流量趋势
  • 排名变化
  • 索引状态
  • 用户行为

分析方法：

  • 对比不同时间段
  • 分析热门页面
  • 找出问题页面
  • 制定优化策略

4. 优化实施 ​

优化步骤：

  1. 发现问题
  2. 分析原因
  3. 制定方案
  4. 实施优化
  5. 监控效果

七、实战案例 ​

案例：使用 GSC 优化网站 ​

背景：

  • 网站流量下降
  • 排名下降
  • 需要找出原因

步骤：

  1. 查看搜索结果报告

    • 发现流量下降 20%
    • 发现某些关键词排名下降
    • 发现点击率下降

  2. 查看索引报告

    • 发现未索引页面增加
    • 发现抓取错误增加
    • 发现服务器错误

  3. 分析问题

    • 服务器不稳定导致抓取错误
    • 某些页面被 noindex
    • 内容质量下降

  4. 实施优化

    • 修复服务器问题
    • 移除 noindex 标签
    • 优化内容质量

  5. 监控效果

    • 流量恢复
    • 排名提升
    • 索引状态改善

结果：

  • 流量增长 30%
  • 排名恢复
  • 索引页面增加

八、常见问题 ​

Q: GSC 数据延迟多久？ ​

A: 通常延迟 2-3 天。实时数据可以在"实时"报告中查看。

Q: 为什么 GSC 数据和 Analytics 不同？ ​

A: 两个工具的统计方式不同。GSC 统计搜索展示和点击，Analytics 统计网站访问。

Q: 如何加快页面索引？ ​

A: 使用 URL 检查工具请求编入索引，确保页面质量高，有内部链接指向。

Q: GSC 显示错误怎么办？ ​

A: 根据错误类型进行修复。优先处理服务器错误和 404 错误。
