# 程序化 SEO

程序化 SEO（Programmatic SEO）是指通过模板和数据批量创建大量页面，以获取搜索引擎流量的方法。本章将介绍程序化 SEO 的原理和实践。

## 一、什么是程序化 SEO？

### 1. 定义

程序化 SEO 是使用模板和数据自动生成大量针对特定关键词的页面的方法。

### 2. 例子

**常见的程序化 SEO 页面：**
- 城市 + 服务页面（如"北京 SEO 服务"）
- 产品比较页面（如"A vs B"）
- 工具结果页面（如"文件类型检查"）
- 目录页面（如"SEO 工具列表"）

### 3. 优点

- **规模化**：可以快速创建大量页面
- **效率高**：模板化操作，节省时间
- **覆盖广**：可以覆盖大量长尾关键词

### 4. 缺点

- **质量风险**：容易产生低质量内容
- **惩罚风险**：可能被 Google 惩罚
- **维护成本**：需要持续更新和优化

## 二、程序化 SEO 的原理

### 1. 关键词矩阵

**创建关键词矩阵：**
```
核心词 + 修饰词
城市 + 服务
产品 + 特性
品牌 + 对比
```

**例子：**
```
SEO 工具
SEO 工具 免费
SEO 工具 推荐
SEO 工具 对比
```

### 2. 模板设计

**页面模板元素：**
- Title 模板
- Description 模板
- H1 模板
- 内容模板
- 内链模板

**例子：**
```
Title: {城市} SEO 服务 - {服务类型} | {品牌名}
H1: {城市} 专业的 SEO 服务
内容: 我们提供 {城市} 地区的 {服务类型} 服务...
```

### 3. 数据准备

**数据来源：**
- 公开数据集
- API 接口
- 爬虫采集
- 用户生成

**数据要求：**
- 准确性
- 完整性
- 时效性
- 唯一性

## 五、新站发布协议：什么时候开始做程序化？

这是程序化 SEO 中最关键、也最容易犯错的问题。

### 新站的定义

满足以下任一条件即为"新站"：
- 域名年龄 < 6-12 个月
- 引用域名 < 100 个
- DR < 40
- 排名前 20 的页面 < 100 个

### 新站绝对不能批量上页面

**新站批量上页面 = 必死**。Google 对新站有"观察期"，批量上页面会触发质量警报。

### 正确的发布节奏

1. **第一阶段（前 3-6 个月）**：一个一个地手做页面，每个页面针对一个关键词，精心优化
2. **第二阶段（当约 100 个页面进入前 20）**：开始小批量程序化，先发 10 个页面
3. **观察**：在 GSC 中观察这 10 个页面的收录和排名情况
4. **扩展**：如果表现良好，逐步扩展到 20、50、100...

::: warning 核心原则
每个页面必须针对一个关键词，遵循"一词一页"原则。不要为了数量牺牲质量。
:::

### 首页新鲜度加速技巧

在首页展示最新的 N 个内页链接，是加速 Googlebot 爬取和新页面收录的可靠方法。有人用这个方法（甚至没有 sitemap），一个月内收录了超过 10 万个页面。原理：Googlebot 最频繁爬取的就是首页，首页上的链接会优先被发现。

## 六、长页面策略：一个 URL 拿下一个关键词的全部意图

Kayak 的 "Cheap New York Car Rentals" 页面是一个经典案例：

- 一个 URL，每年从谷歌获取约 **62 万次点击**
- 页面整合了：租车表单、价格对比、使用技巧、FAQ、用户评价、地点目录、教程、机场信息、热门车型
- Kayak 整体月访问量 4000 万，40% 来自自然搜索

**核心思路：** 不要为一个关键词的每个子意图做单独的页面，而是一个长页面覆盖该关键词的所有用户意图。用模块化的方式组合内容。

## 七、共识驱动搜索需求（CDSD）理论

搜索量的本质是什么？**搜索量来自于共识**——多个人独立地用相同的词语表达相同的需求。

**实战案例：**
getimg.ai 在 "Ghibli AI" 社交媒体热潮出现后，快速发布了一个落地页。结果：一个月内月访问量从 160 万暴涨到 **1240 万**（增长 1080 万）。

**核心公式：** 新需求 + 先发 SEO = 以最小竞争获取巨大流量

**实操建议：**
- 用 Google Trends 监控新兴趋势
- 发现新需求后，第一时间发布落地页
- 新词的 KGR 通常极低，排名速度极快

## 八、避免低质量程序化 SEO

### 1. 低质量特征

**常见问题：**
- 内容重复或相似
- 内容过薄
- 关键词堆砌
- 用户体验差
- 没有价值

### 2. Google 的惩罚

**惩罚类型：**
- 手动惩罚
- 算法惩罚
- 降权
- 去索引

**惩罚信号：**
- 流量突然下降
- 排名下降
- 索引页面减少
- GSC 收到通知

### 3. 避免方法

**质量控制：**
- 确保内容有价值
- 避免重复内容
- 提供独特信息
- 优化用户体验

**技术控制：**
- 使用 canonical 标签
- 合理使用 noindex
- 控制页面数量
- 定期质量检查

## 十一、常见问题

### Q: 程序化 SEO 还有效吗？

A: 有效，但需要更注重质量。Google 越来越智能，能够识别低质量的程序化页面。

### Q: 程序化 SEO 需要多少页面？

A: 取决于关键词数量和竞争度。关键是每个页面都要有质量，而不是数量。

### Q: 如何避免被惩罚？

A: 确保每个页面都有独特价值，避免重复内容，提供有用的用户体验。

### Q: 程序化 SEO 适合什么类型的网站？

A: 适合工具网站、目录网站、本地服务网站等有大量结构化数据的网站。
