# 关键词研究基础

关键词研究是 SEO 的第一步，也是最重要的一步。找到正确的关键词，才能创建有针对性的内容，获得目标流量。

## 一、什么是关键词研究？

关键词研究是发现和分析用户在搜索引擎中使用的搜索词的过程。目的是找到：
- 有搜索量的关键词
- 竞争度适中的关键词
- 与业务相关的关键词

## 二、关键词类型

### 1. 按搜索意图分类

- **信息型**：用户想了解信息（如"什么是 SEO"）
- **导航型**：用户想找特定网站（如"GitHub 登录"）
- **商业型**：用户想比较产品（如"最好的 SEO 工具"）
- **交易型**：用户想购买（如"购买 SEO 课程"）

### 2. 按关键词长度分类

- **短尾关键词**：1-2 个词（如"SEO"）
  - 搜索量大
  - 竞争激烈
  - 转化率低

- **长尾关键词**：3 个以上词（如"如何做好 Google SEO"）
  - 搜索量小
  - 竞争度低
  - 转化率高

::: tip 建议
新站应该优先做长尾关键词，积累权重后再做短尾关键词。
:::

## 三、关键词研究步骤

### 第 1 步：确定种子关键词

种子关键词是与你的业务相关的基础关键词。

**方法：**
- 列出你的产品或服务
- 思考用户会搜索什么
- 分析竞争对手的关键词

### 第 2 步：扩展关键词列表

使用工具扩展关键词：

**免费工具：**
- Google 搜索建议
- Google 相关搜索
- Google Keyword Planner
- Answer The Public

**付费工具：**
- Ahrefs
- SEMrush
- Moz

### 第 3 步：分析关键词指标

重要的关键词指标：

1. **搜索量**：每月搜索次数
2. **竞争度**：排名难易程度
3. **CPC**：每次点击成本（可判断商业价值）
4. **关键词难度**：SEO 排名难度

### 第 4 步：筛选关键词

选择关键词的标准：

- ✅ 有搜索量
- ✅ 竞争度适中
- ✅ 与业务相关
- ✅ 有商业价值
- ❌ 避免竞争度过高的词
- ❌ 避免搜索量过低的词

## 四、关键词研究技巧

### 1. 使用 KGR 公式

KGR（Keyword Golden Ratio）是筛选低竞争关键词的公式：

```
KGR = allintitle 结果数 / 月搜索量
```

- KGR < 0.25：容易排名
- KGR 0.25-1：中等难度
- KGR > 1：竞争激烈

**使用方法：**
在 Google 搜索 `allintitle:你的关键词`，查看结果数量。

### 2. 分析竞争对手

**步骤：**
1. 找到竞争对手网站
2. 使用工具查看他们的关键词
3. 找出他们排名好但竞争度低的关键词
4. 创建比他们更好的内容

### 3. 利用 Google 搜索建议

在 Google 搜索框输入关键词，查看下拉建议：

```
SEO 教程
SEO 教程 入门
SEO 教程 免费
SEO 教程 实战
```

### 4. 查看相关搜索

在搜索结果页面底部，查看"相关搜索"：

这些是 Google 认为与你的搜索相关的关键词，可以作为内容创作的参考。

### 5. 利用 Google Trends

Google Trends 可以：
- 查看关键词搜索趋势
- 比较不同关键词的热度
- 发现新兴关键词
- 了解地域分布

## 五、关键词布局

### 1. 首页关键词

- 选择 1-2 个核心关键词
- 在 Title、H1、Description 中使用
- 在正文中自然出现

### 2. 分类页面关键词

- 选择中等竞争度的关键词
- 围绕主题创建内容
- 合理使用内链

### 3. 内容页面关键词

- 选择长尾关键词
- 创建针对性的内容
- 链接到相关页面

### 4. 关键词密度

- 自然使用关键词
- 避免关键词堆砌
- 使用语义相关的词
- 一般建议 1-2%

## 六、常见错误

### 1. 只关注搜索量

搜索量大的词不一定适合你，要考虑竞争度和相关性。

### 2. 忽视搜索意图

关键词背后的用户意图很重要，内容要匹配用户需求。

### 3. 关键词堆砌

在页面中过度使用关键词会被 Google 惩罚。

### 4. 不做长尾词

长尾词虽然搜索量小，但竞争度低，转化率高。

### 5. 不更新关键词

搜索趋势会变化，定期更新关键词策略。

## 七、关键词研究工具推荐

### 免费工具

1. **Google Keyword Planner**
   - 官方工具，数据准确
   - 需要 Google Ads 账号

2. **Google 搜索建议**
   - 直接在搜索框查看
   - 反映真实搜索需求

3. **Answer The Public**
   - 展示问题型关键词
   - 适合内容创作

4. **Ubersuggest**
   - 免费版本可用
   - 提供关键词建议

### 付费工具

1. **Ahrefs**
   - 数据全面
   - 竞争分析强大

2. **SEMrush**
   - 功能丰富
   - 竞争对手分析

3. **Moz**
   - 关键词难度评分
   - SERP 分析

## 八、实战案例

### 案例：为工具网站做关键词研究

假设你做了一个"文件类型检查"工具：

1. **种子关键词**：file type checker, file type detector

2. **扩展关键词**：
   - how to check file type
   - identify file type
   - what type of file is this
   - file extension checker

3. **筛选标准**：
   - 搜索量 > 100/月
   - 竞争度 < 30
   - 与工具功能相关

4. **最终选择**：
   - 首页：file type checker
   - 内页：how to check file type on windows

::: tip 关键要点
关键词研究是 SEO 的基础。花时间做好关键词研究，可以让你的 SEO 工作事半功倍。记住，选择正确的关键词比努力优化错误的关键词更重要。
:::
