# Google 排名因素

了解 Google 的排名因素是做好 SEO 的关键。本章将介绍影响 Google 排名的主要因素。

## 一、内容相关性因素

### 1. Title 标签（权重：15%）

Title 标签是告诉搜索引擎页面主题的最重要元素。

**最佳实践：**
- 每个页面有唯一的 Title
- 长度控制在 50-60 个字符
- 将重要关键词放在前面
- 在结尾加上品牌名称

```html
<title>关键词 - 页面描述 | 品牌名</title>
```

### 2. 内容质量

高质量内容的特征：
- **原创性**：不要抄袭或复制内容
- **深度**：全面深入地讲解主题
- **实用性**：对用户有实际帮助
- **权威性**：专业可信的内容
- **时效性**：保持内容更新

### 3. 内容相关性

- 整个网站围绕核心主题
- 页面内容与 Title 和 H1 匹配
- 使用语义相关的关键词

## 二、技术 SEO 因素

### 1. 页面加载速度

Google 明确表示页面速度是排名因素。

**优化建议：**
- 压缩图片
- 启用浏览器缓存
- 使用 CDN
- 减少 HTTP 请求
- 压缩 CSS 和 JavaScript

### 2. 移动端适配

Google 使用移动优先索引，移动端体验非常重要。

**检查方法：**
- 使用 Google 的移动设备适合性测试
- 确保文字可读，无需缩放
- 按钮大小适合点击
- 避免使用 Flash

### 3. HTTPS

HTTPS 是排名因素之一，确保网站使用 SSL 证书。

### 4. 网站架构

- 清晰的层级结构
- 合理的内部链接
- 页面深度不超过 3 层
- 使用面包屑导航

## 三、用户体验因素

### 1. 用户停留时间

用户在页面停留的时间越长，Google 认为页面越能满足用户需求。

**提升方法：**
- 创建有价值的内容
- 使用多媒体元素
- 优化页面布局
- 提供相关内容推荐

### 2. 跳出率

跳出率低表示用户愿意继续浏览网站。

**降低跳出率：**
- 提供清晰的导航
- 添加相关内容链接
- 优化页面设计
- 提升内容质量

### 3. 点击率（CTR）

搜索结果的点击率会影响排名。

**提升 CTR：**
- 编写吸引人的 Title
- 优化 Meta Description
- 使用结构化数据
- 获取 Sitelinks

## 四、外链因素

### 1. 外链数量和质量

外链是其他网站指向你网站的链接，是重要的排名因素。

**质量指标：**
- 来源网站的权重
- 来源页面的相关性
- 链接的锚文本
- 链接的位置

### 2. Dofollow vs Nofollow

- **Dofollow**：传递权重
- **Nofollow**：最初不传递权重，但现在也有一定作用

::: tip 提示
不要只追求 Dofollow 外链，Nofollow 外链也有价值，有就要。
:::

### 3. 锚文本

锚文本是链接的文字部分，应该包含相关关键词，但要自然。

## 五、On-Page SEO 因素

### 1. H1 标签

每个页面应该有且只有一个 H1 标签，包含主要关键词。

### 2. Headings 层级

合理使用 H1-H6 标签来组织内容结构：
- H1：页面主题
- H2：主要章节
- H3：子章节
- H4-H6：更细的划分

### 3. 图片优化

- 使用描述性的文件名
- 添加 Alt 属性
- 压缩图片大小
- 使用合适的图片格式

### 4. 内部链接

- 使用描述性的锚文本
- 链接到相关页面
- 保持合理的链接数量
- 重要页面获得更多内链

## 七、排名因素总结

### 影响排名的关键点

1. **Title 和 H1**：确保页面能够进入关键词搜索的待排名范围
2. **外链**：帮助页面进入搜索结果前 10 位
3. **网站体验**：确定最终的排名位置

### 需要避免的做法

- 关键词堆砌
- 购买外链
- 隐藏文本或链接
- 内容抄袭
- 门页（Doorway Pages）
- 链接农场

::: warning 注意
Google 的排名算法在不断更新，不要试图操纵排名，而是专注于为用户创造价值。
:::
