# 如何低成本的养着一个网站 为什么要继续养着网站 

如何低成本的养着一个网站？

为什么要继续养着网站？

大家好，我是哥飞。

前几天，哥飞在社群里发了一张截图，配文是：“没流量的网站不要丢，你就放着，说不定时不时就蹦出个99刀。

”这个站相对于巅峰时期，流量的确跌成狗了，给大家看看下面的GSC里的点击数据变化趋势图就明白了。

从上图可以看到，12月15日后，流量就跌了一大截了，后面一直都很稳定，嗯，稳定在很低的量。

那么从12月16日到今天3月15日，这个站的总收入是多少呢？

的确不多，91个订单，1943美元，聊胜于无。

虽说不到2000美金，但也是钱，换算成人民币之后也有一万四千块钱呢。

那么，这期间的服务器成本是多少呢？

因为是放在 Vercel 上的，按照访问量计费，所以这个站的服务器成本可以忽略不计。

这就是为什么哥飞一直推荐大家用 Vercel 等平台来部署自己网站的原因，他们直接按照访问量收费，你网站流量小，就可以一直免费使用。

当你网站流量大了，虽然这些平台会开始收费了，但是你流量大了能赚钱了，分一点点钱给平台买基础服务，也很合理嘛。

哥飞第一个网站，大约是2008年上线的，当时买的还是PHP虚拟空间。

后来还买过完整的VPS，一台服务器里可以放N个网站。

但是这么多年下来，之前的那些老网站都因为服务器迁移的原因，慢慢关站了。

这是哥飞觉得最可惜的事情。

本来这些网站，都可以随着时间的推移，拿到越来越多的外链，进而拿到更多的流量，长期的赚下去。

不过当时做的好多都是中文站，上面的设想不一定正确。

举例，现在哥飞手上还在线上运行的年龄最久的网站，是2012年2月上线的秋玉米。

但是这个站只做了中文，面向的也是国内用户，所以现在已经几乎没流量了。

最近一年的的PV才两万七，UV才一万六。

实际Adsense监测到的放了广告的页面PV是一万九，带来的收入是45美金，是的，你没看错，一年才45美元。

这些钱，够续费域名了，服务器又几乎不要钱，于是就可以一年一年养下去，一直养了13年了。

那么，养了那么久，有没有啥别的成果了？

看下图，还是有的，这么多年下来，外链域名数量有610个了，域名DR也达到了52了。

现在秋玉米功能几乎不可用了，后面有空，我用 Cursor 辅助，做一个新版，并且主打英文，试试看这个有一定权重的域名，是否可以救回来。

如果有后续，我也会在公众号里跟大家介绍。

说了这么多，想表达什么呢？

只要你养一个网站的成本足够低，如服务器几乎不要钱，那么你的网站只需要每年能够赚回域名费用，就可以长期的养下去了。

毕竟，很多人关掉网站的两个主要原因，一是服务器有成本，二是域名续费需要钱。

只要这两个因素搞定了，就可以长期养着一个网站了。

养着的老网站，还可以给自己的新网站加反向链接，帮助新站快速被收录，可以说是好处多多。
