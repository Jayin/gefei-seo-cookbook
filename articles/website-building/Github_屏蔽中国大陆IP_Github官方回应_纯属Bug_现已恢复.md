# Github 屏蔽中国大陆IP Github官方回应 纯属Bug 现已恢复

Github 屏蔽中国大陆IP？

Github官方回应：纯属Bug，现已恢复 大家好，我是哥飞。

昨天技术圈传得沸沸扬扬，说Github主动屏蔽了中国大陆 IP，在目前中美关系这么敏感的时间点下，事件影响被无限放大，不少人还在紧急搬运项目回国。

大家的具体反映，哥飞就不一一在这篇文章里还原了。

哥飞写这篇文章，是因为看到了 Github 的官方公告，见下图。

公告地址：https://www.githubstatus.com/incidents/jfvgcls9swln哥飞给大家翻译一下，并且把时间也改成北京时间了：[追溯性报告] 未登录用户暂时无法从中国访问GitHub 事件报告已解决由于一项配置变更产生了意外影响，未登录用户在尝试从中国访问 GitHub.com 时暂时无法访问该网站。

对于已经登录的用户，他们可以继续成功访问网站。

影响开始于北京时间 2025 年 4 月 13 日 04:01。

影响已于北京时间 2025 年 4 月 13 日 22:55 缓解。

导致此影响的配置变更已被撤销，用户在尝试访问 GitHub.com 时应不再遇到问题。

发布于 1 天前。

2025 年 4 月 13 日 - 北京时间 04:00总之，今天凌晨4点，Github在 githubstatus.com 发布公告，称这次从13日凌晨4点到22:55分期间发生的事故，原因是配置变更产生的意外Bug，并不是主动屏蔽中国大陆IP。

事故在北京时间昨天（4月13日）晚上22点55分缓解。

其实昨天就有非中国大陆地区网友，如香港地区和新加坡的网友，报告说他们也被屏蔽了。

所以的确更像是 Bug，而不是有意针对。

昨天甚至有人猜测跟 OpenAI 有关，那就更是无稽之谈了。
