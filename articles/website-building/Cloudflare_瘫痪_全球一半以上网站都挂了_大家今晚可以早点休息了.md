# Cloudflare 瘫痪 全球一半以上网站都挂了 大家今晚可以早点休息了

Cloudflare 瘫痪：全球一半以上网站都挂了，大家今晚可以早点休息了 大家好，我是哥飞。

如上图所示，哥飞社群配套网站暂时无法访问，原因是 Cloudflare 出故障了，导致无法访问。

甚至于，如下图，Cloudflare 的后台都登录不上了。

Cloudflare 这次挂得有点久，两三个小时了，上全球新闻头条了。

CF 挂了之后，全球很多网站都打不开了，如 ChatGPT 用了 Cloudflare 的人机识别服务，所以暂时无法访问。

同样的，Claude 也挂了。

全球最大的 AI 导航网站 There's An AI For That 也挂了。

我们调用的 AI API 平台 Replicate 也挂了，对了，前两天 Cloudflare 刚宣布收购了 Replicate 。

Twitter 也挂了。

Reddit 没挂，大家正在上面讨论 Cloudfalre 挂了的新闻。

有一张有意思的梗图，每次哪个互联网基建服务出事，就会被拿出来做成新图在全世界传播。

这次，有人把 CF 比喻为整个互联网基建的那两条细腿。

哥飞群里，今天大家就一直在讨论这个问题，但是也只是讨论，无计可施。

因为我们的服务大量使用了 CF 的基建，所以即使让网站恢复访问量，功能也会受影响，所以也就不做任何动作，就等着 CF 去恢复吧。

反正全球半数网站都挂了，是大新闻了，我们的用户也应该知道了。

好了，今晚的闲聊就到这里了。

大家早点洗洗睡吧！
