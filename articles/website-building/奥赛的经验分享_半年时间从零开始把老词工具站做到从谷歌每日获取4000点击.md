Morse Code工具站经验分享作者：奥赛
一、成果展示大家好，我做的是一个关于 Morse Code的网站。

先给大家看下我的成果，大概半年多的时间，流量从0慢慢增长到现在每天4K多UV，8-9K PV这个成果虽然比不上群里的各位大佬，但是对我来说却是真正做到了从0到1，证实了这是一条可以长期持续投入的道路当然，我其实做了
1、20个网站，但只有这个网站起来了，成功率还是挺低的
二、个人简介我先简单做个自我介绍我的主业是Android工程师，对SEO、网站开发了解比较少之所以会接触SEO和出海，主要是去年上半年加入生财，在一次同城聚会中认识了一个做电商独立站的大佬后来就开始学习SEO，学习用WordPress搭建电商站后来发现电商站涉及的东西太多太杂了，不是很适合我这样的技术宅再后来是在去年下半年看到哥飞的公众号文章，慢慢跟着学习SEO和网站知识，但这时候还处于观望、学习的状态，还没开始实践直到今天年初参加了生财的航海实战，看着航线图怎么跟哥飞公众号的内容这么像呢，后来了解到航海手册里大部分内容就是基于哥飞公众号文章整理出来的：挖掘需求、分析搜索意图、开发网站核心功能、开发内页、部署上线、添加统计代码、添加外链、变现生财航线图哥飞公众号然后我就添加了哥飞的微信，加入了哥飞的朋友们VIP群后面就跟着航海、跟着哥飞的分享慢慢开始做网站下面我就从这几个方面分享一下我的经验 
1、挖掘需求，验证需求是否可以做 
2、绘制原型 
3、开发历程 
4、外链
三、经验分享
1、挖掘需求，更准确地说是验证需求是否可以做关注到这个词：Morse Code，主要是哥飞在群里分享过，他用这个词做了一个网站，用来验证KGR公式这个公式主要就是在谷歌搜索结果中，看这个关键词 allintitle页面数量，除以搜索量（SemRush、SimilarWeb等查询）KGR < 0.25，难度比较低 KGR 在 0.25 - 1.00直接，难度中等 KGR > 1.00，难度较大然后我就在 SemRush上搜索 morse code，然后把 morse code相关的几个搜索量比较大的关键词都拿出来计算KGR我发现除了主词 morse code 的KGR比较高，其他的长尾词 KGR都是挺低的，证明这个词是可以做的。

验证完需求后，我就去了解了一下 morse code 相关的一些知识信息源主要是维基百科，还有一些竞争对手的网站，看他们是怎么做的然后我把SemRush下载下来的关键词列表，整理成一个思维导图，这样就知道后面要做哪些内页、每个内页分别要用哪些关键词
2、绘制原型接下来主要是借鉴我之前做Android开发的经验我用墨刀绘制了第一版几个主要页面的原型，比较粗糙，但是画出来以后，整个网站页面框架就比较清晰了其实第一版的网站框架参考了哥飞的 morsecodeai.com 的结构
3、开发历程网站是4月底开始开发，后面断断续续一直到5月底才上线，然后就一直放着没管了，每天也只有几十个点击一直到8月底，每天大概有500+点击然后我就去申请Google AdSense，在网站上挂了广告但这时候每天只有零点几美元，然后开了10几天我就关掉了后面国庆的时候，我想着虽然钱不多，但蚊子再小也是肉啊，然后就重新打开了广告后面到了10月中旬，每天大概有1000多个用户看着慢慢有点起色的用户量和AdSense收入，一下子又有了动力我就借助ChatGPT，把核心关键词发给他，让他帮忙生成文案这时候回头看之前的网页内容，真的是非常粗糙，甚至可以说是堆砌关键词，内容短、关键词密度大部分高达10几、20几然后我就慢慢地把所有页面内容都更新了一轮，然后流量也慢慢又涨了一波现在每天大概是
4、5000用户
4、外链外链这块，其实是我的弱项，或者说对这块不感兴趣，一直有点排斥最开始发了 ProductHunt、V2EX、Hacker News，还有几个导航站中间根据群友分享的外链网站，整理了一份一两百个可以发外链的网站但是我陆陆续续只发了
1、20个导航站，后面就没做了，导致现在DA一直很低后面有时间，还是应该多做一些外链
四、总结最后总结一下信哥飞，多上站，搞流量，赚美元还是要动手做，然后想办法赶快赚到第一块美元有了正反馈，你就会有足够的动力谢谢大家从奥赛到成功经验，以及哥飞了解到的社群里其他朋友的经验，以及哥飞自己的实践来看，老词也是可以做的，大家没必要扎堆去做新词。

或者说，有新词时做新词，没新词时老词也值得投入去做。

几个月的时间，也可以拿下老词的排名。
