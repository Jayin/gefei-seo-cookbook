# 出海两年 终于日入万刀了 真难啊 

出海两年，终于日入万刀了，真难啊！

大家好，我是哥飞。

今天跟大家官宣两个好消息。

小说第一个消息，哥飞公司出海业务，终于在8月28日突破日入万刀这个门槛了。

这个消息，当天晚上哥飞已经在社群里跟大家分享过了，当时还没到 0 点，所以当时的数据是 10039.94，而刚刚最新截图的数据固定下来了，是 10059.74 美元。

注意国家实际上有很多行，为了截图方便，哥飞去掉了中间的很多行，只保留了前两个国家和最后一个国家。

另外还要说明的是，哥飞不是单打独斗，哥飞有一个十几个人的 Web 出海团队，成员包括开发、产品、运营、编辑等各种岗位。

所以这个日入万刀的成绩，不是哥飞一个人做出来的，是十几个人的成果。

并且，万刀并不都是利润，这只是营收。

要算利润的还，还需要扣除 API 成本、人员成本、广告成本等等各种成本，所以实际利润并不多。

好了，上面说了那么多，就是想告诉大家，其实日入万刀并没有那么容易。

注意，哥飞说的不是“并没有那么难”，而是“并没有那么容易”。

为什么？

因为哥飞知道那有多难。

哥飞从 2023 年中单打独斗到 23 年底开始组建团队，到现在十几个人的团队，两年过去了，才达到这个数字。

比哥飞更牛的人多了去了，如哥飞社群里就有彪哥、杉木哥、阿北等等，他们都做得更大。

而且他们还很平易近人，在群里也会时不时分享自己的观点，我们去他们公司拜访，他们不仅请吃饭，还倾囊相授，把自己的踩过的坑，得到的经验都分享给我们。

所以哥飞很感谢他们，正是因为他们的存在，才让这个世界更美好。

不过，他们毕竟事业繁忙，不可能出来天天写文章教大家怎么出海，或者天天在群里分享。

刚好，哥飞是个话唠，一直是个话唠，总是有很多话想说。

在还没有微信朋友圈的年代，哥飞能在 QQ 空间里一天发十几条说说。

后来有了朋友圈，哥飞就能够一天发十几二十条朋友圈。

再后来，哥飞在 V2EX 活跃过，目前主要在即刻和公众号活跃。

即刻发短篇，几十字上百字几百字都有，公众号发中长篇，几百字到几千字的文章。

所以站出来教人做出海网站赚钱，靠 SEO 获取流量这事，哥飞自然而然就做了。

之前总有人说，大神都忙着自己赚钱，不会出来教人。

这句话是对的，彪哥他们都在忙着自己公司的业务，肯定是没时间来做社群的。

但是，教人这件事情，其实并不一定要大神才能做好。

哥飞就能做好啊。

为什么？

因为教人，最重要的是要有耐心和爱心。

而这两个，哥飞都有。

长期的坚持输出，靠耐心。

不厌其烦的回答小白问题，靠爱心。

在公众号一年写几百篇文章，靠耐心。

在社群里不断鼓励大家，靠爱心。

每天在群里分享，这件事情，哥飞已经坚持两年了，而且目前看起来，还能继续坚持下去。

不过，随着社群参与人数越来越多，影响力越来越大，不可避免的就有人来黑哥飞，很难说清楚他们的动机，因为人性是复杂的。

而且几乎都是完全没进社群的人，对于我们社群一无所知，甚至哥飞公众号里的免费教程文章都没看几篇，就凭借着臆想和猜测，就来说哥飞割韭菜。

即刻就有一个人，特有意思，假装加过哥飞社群，然后在那里黑哥飞，但实际上观察了一周多他的发言后就得出结论了，这人压根就没进过哥飞社群。

也就是说，有些人为了黑哥飞，不惜撒谎。

还有人，因为在教学质量方面找不到黑哥飞的点，于是就抓住社群里有人没赚到钱来说事。

前几周，哥飞曾经为此伤心过，不过很快，哥飞就想通了。

因为任何一个老师，都没办法保证 100% 的成材率。

哥飞只要保证，通过哥飞的教学，把社群里愿意学，愿意实践，会执行的人带出成绩就够了，如果一个人硬是不主动学习，那么再好的老师都没办法，当然，高价的一对一教学除外。

而过去两年，哥飞的确也带出来了很多做出成绩的人。

只要是加了哥飞社群的朋友，都能够看到这些成绩。

好的，我们回到日入万刀这个话题，大家还记得之前哥飞给出的一个升级打怪路线图吗？

当时给出收入顶峰 Level 10 是日入 10000 美元，现在看来，的确是当时的哥飞眼界有点小了。

主要是自己没做到，就会心虚，不敢说更大的数字。

但现在自己做到了，也许后面哥飞就可以在后面补充两个等级了。

一个等级是日入 5 万美元，一个等级是日入 33 万美元。

为什么是这两个数字？

因为日入 5 万，一个月就是 150 万美元，再乘以 7 点几的汇率，刚好就是月入 1000 万人民币。

而日入 33 万美元，月入是 1000 万美元。

看到没有，就是为了凑 1000 这个数字而已。

有没有人能够日入更多？

当然有，但其实对我们大家已经没有参考意义了。

其实，当月入超过 5 万美元时，仅仅靠单打独斗可能已经忙不过来了，需要开始组建团队了。

不过团队也不需要一开始就很多人，可以先从一两个人开始，到三四个人，到七八个人，到十几个人。

哥飞出海团队，目前总人数，不加哥飞是 15 人，加上哥飞就是 16 人了。

这些人里有三个负责社群业务，剩下 13 个人都是只做出海 Web 业务。

而今天跟 Damo 聊了之后，觉得还需要继续加人，主要是加运营和编辑两个岗位。

但现在办公室每一个位置都坐满人了，已经加不了新位置了，于是，哥飞今天把现办公室隔壁的办公室也租下来了。

这就是今天哥飞要跟大家官宣的第二个消息。

这个办公室上一任租客在今年 4 月份就退租了，早前哥飞就在犹豫，要不要租下来，因为就在隔壁，得天独厚的条件，很方便了。

而且都不用装修，直接打扫一下摆上桌子，就可以办公了。
