# 找出单月新增590万的网页 谷歌 Site 语法的五种用法 最后一种你绝对想不到

找出单月新增590万的网页：谷歌 Site 语法的五种用法，最后一种你绝对想不到 大家好，我是哥飞。

2023年9月，哥飞写了《分享几个实用的谷歌搜索高级语法》，里边也提到了 Site 语法，不过只讲了一种用法，今天这篇文章，我们讲讲 Site 语法的五种用法。

其中最后一种，能够有效的帮助你的网站更好的被谷歌收录。

第一种用法，你可以直接 site 域名后缀，如 site:.org ，就可以看到所有的用 org 域名的网页结果。

用这个方法可以对比不同后缀的网页数量，从而判断要不要买某个小众后缀。

网页数量需要点击搜索框下方的 tools 才能看到。

第二种用法，大家就比较熟悉了，直接 site 某个域名，如 site:github.io ，看这个域名下的网页结果，和被收录的网页数量。

如果这个域名还提供子域名的话，第二种用法，还可以找出子域名。

第三种用法，查某个子域名下的网页结果。

上周我们分享一个最近流量暴增的 github.io 子域名 iseej.github.io ，如果你直接打开首页，会发现 404 了。

其实是因为他没有配置首页，只配置了内页，那么怎么找到他的内页呢？

就可以用 site:iseej.github.io 实现。

可以看到，这个域名在2月有592万的访问量，而1月的访问量是2万。

从2万到592万，是怎么做到的呢？

刚才 site 查询出来的结果里就有答案。

第四种用法，查询某个域名下的某个目录下的结果，如 V2EX 就用这个做站内搜索。

site:v2ex.com/t 表示搜索域名 v2ex.com 下以 /t 为开头的网页第五种用法，直接查询某个 url ，主要用途是看是否被收录了，看显示出来的标题、描述、图标等是否正确。

杉木哥的 toolify.ai 就用这个方法判断最新发布的页面是否被收录了。

如果没有被收录，则继续在首页曝光，尽量让谷歌爬虫看到，增加被收录的几率。
