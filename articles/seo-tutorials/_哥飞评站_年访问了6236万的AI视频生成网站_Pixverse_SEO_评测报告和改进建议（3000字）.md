#  哥飞评站 年访问了6236万的AI视频生成网站 Pixverse SEO 评测报告和改进建议（3000字）

【哥飞评站】年访问了6236万的AI视频生成网站 Pixverse SEO 评测报告和改进建议（3000字） 大家好，我是哥飞。

上一篇【哥飞评站】系列还是去年3月写的《【哥飞评站】AI贴纸生成网站 StickerBaker 的SEO评测报告和改进建议（4000字）》，都过去一年多了。

今天哥飞给大家打来这个系列的第二篇文章，我们评测的网站是 Pixverse ，这是国内创业公司爱诗科技开发的出海网站。

我们先看下这个网站的基本情况，域名 pixverse.ai 注册于2023年10月，目前网站月访问量1117万，过去12个月总访问量是6236万，最高峰是2025年1月的1331万。

这个访问量，对于一个上线16个月的网站来说，是很不错的成绩了。

过去12个月，有40.13%流量来自于直接打开，有38.63%流量来自于自然搜索，有4.81%来自于付费广告，11.2%流量来自于外链，5.11%来自于社交媒体。

不管是超过40%的直接访问，还是38%的自然搜索，更或者是5%的社交流量，都说明 Pixverse 的品牌很强。

从 Pixverse 和 Pixverse AI 两个词的谷歌趋势也可以看出来，是GPTs的40倍，品牌热度的确很高。

过去12个月，Pixverse 从搜索引擎获得了2410万访问量，其中15%左右是PC端访问，85%左右是移动端访问。

如果只从量来说，2410万是很大的数字了，但是如果我们再去看流量来源关键词，就会发现，Pixverse 尽管有2600多个外链，并且域名 DR 达到了61，但哥飞依然觉得，Pixverse SEO 工作做得并不好，或者说，压根就没有做任何SEO。

这些外链，都是品牌宣传之后，得到的自然外链。

为什么说没有做任何SEO呢？

从 Pixverse 网站获取的自然搜索流量关键词可以看出一些端倪。

从上图可以看出来，前 20 关键词，居然都是品牌词相关关键词。

后面也都是品牌词，截图太长了，哥飞没放出来。

直到第50名，才出现了一个非品牌词 Image to Video ，51名之后到100名又都是品牌词。

这很不正常。

一个这么大访问量的网站，并且搜索流量还占比38.6%，正常来说，不可能全都是品牌词流量。

但偏偏 Pixverse 目前却是这个情况，原因就在于，Pixverse 没有做任何SEO。

下面哥飞带着大家一一查看，并说明为什么SEO没做好，以及要怎么改进。

第一点，没用主域名，而是用了 app 子域名。

从上面两个截图可以看到，不管是打开 pixverse.ai 还是 www.pixverse.ai ，都会自动跳转到 app.pixverse.ai 。

哥飞猜测，他们一开始想学海外公司落地页V1.5做法，核心产品放 app 子域名，自己开发。

而www则放官网落地页，使用第三方平台。

但是不知道什么原因，
第二步一直没去做，于是就只好把主域名跳转到app子域名。

这里哥飞的建议是，如果是一个全新网站，直接用哥飞在《出海网站落地页的1.0到1.5版本，2.0再到2.5版本》讲解过的落地页V2.0做法，就不要把产品核心功能放在 app 子域名下了，而是直接放在主域名下，并且把落地页也放在这个域名下，自己开发。

但是 Pixverse 现在已经用了 app 子域名，就不宜改动了，将错就错即可，继续使用目前的方案，主域名跳转到 app 子域名即可。

第二点，没用后端渲染，而是用了前端渲染。

如果打开 https://app.pixverse.ai/ 可以观察到，浏览器里的URL很快被替换为了 https://app.pixverse.ai/onboard 。

一开始哥飞以为是从 / 跳转到了 /onboard ，后来仔细研究了一下，没有发生后端或者前端跳转，是用了浏览器提供的 url history 接口，通过JS代码，强行把 / 改成了 /onboard 了。

更有意思的是，随便你输入什么网址，如https://app.pixverse.ai/gefeiseo 也会自动被修正为 https://app.pixverse.ai/onboard 。

这些都是前端JS做的工作。

这就说明，这个网站，纯纯前端渲染的，不管你输入任何网址，其实后端返回的都是同一段 html 代码。

从上面截图也可以看到，整个网页144行代码，其中 body 部分就几行，典型的纯前端渲染网站。

所有的网页内容都是靠JS在浏览器前端渲染出来的。

这就可以解释，为什么这个网站的主要流量来源关键词，都是品牌词了，因为他压根就没有可以用于获取其他关键词的页面。

所以谷歌也没收录多少页面，只收录了208个页面，这估计还是因为这些页面的网址出现在了别的网站上，被谷歌爬到了，于是就收录了。

这里哥飞的建议是，出海网站千万别放弃SEO，这是海外很大一块流量来源。

为了做好SEO，就需要使用后端渲染，而不是前端渲染。

至于为什么要这么做，可以在#视频号：哥飞出海 的直播回放里看到，哥飞之前做的一期SEO扫盲公益培训直播回放视频里可以看到详细的讲解。

对于 Pixverse 来说，目前的底子不错，因为通过 url history 接口区分了不同页面的 URL ，那么直接在目前的基础上，保持 URL 不变，改成后端渲染就好了。

工程师可能会觉得麻烦，但是这个麻烦还是值得去花时间花资源去解决掉的，因为收益足够高。

第三点，多语言没用URL区分，而是直接JS切换。

从下面截图可以看到，当用日本IP访问时，URL还是 /onboard ，但是语言已经变成了日语。

当通过右上角的语言切换按钮把语言切换成韩语时，也是 URL 没变。

这就说明，目前的多语言是直接在前端切换的，这也是SEO不友好的。

这样做，爬虫就只能抓取到爬虫服务器所在IP地区对应的语言，网站拿不到其他语言的搜索流量。

更好的做法是用子目录 / 默认英语，/ko/ 是韩语，/ja/ 是日语。

对于 Pixverse ，哥飞的建议是，用 URL 查询参数，即 / 默认英语，/?lang=ko 是韩语，/?lang=ja 是日语。

同时用 Canonical 设置好每个语言的规范 URL ，用 Hreflangs 设置好 URL 和语言的对应关系。

第四点，标题只写了品牌名称，而没有写业务需求关键词。

从下面截图可以看到，首页只写了 Home 这个没啥意义的单词，以及 Pixverse 这个品牌词。

其实即使 Pixverse 保持现在的代码不做任何变化，只需要修改首页标题，把 AI Video Generator、Image to Video 等相关关键词加上去，也能够带来更多的搜索流量。

因为现在他们网站有2500个外链域名，DR60，足够拿下一些关键词排名了。

所以这里哥飞的建议是，可以花10分钟改改首页标题，然后把网站提交到GSC，申请重新抓取收录网站，接下来半个月时间，去观察是否有除了品牌词之外的 AI Video 相关关键词搜索流量进来。

如果有，就证明哥飞说的方法是可行的，再进行其他更改。

如果没有……那是不可能的，肯定会有的。

另外附送一个建议，在首页代码 id 为 root 的 div 下方，增加一个 id 为 introduction 的 div ，用来放图文介绍。

围绕着品牌词 Pixverse 和业务关键词 AI Video Generator、Image to Video、AI Kiss等关键词，去写图文介绍。

不需要太多，写1200个单词就可以了，不能乱写，一定要围绕着业务相关的有搜索量的关键词去写。

这样的好处是，目前的前端渲染代码不需要做任何改动，只需要修改 html 文件，多返回一个 div 即可变得 SEO 友好。

当然，更进阶的改动，对于直接打开的不同 URL ，后端能够识别到，然后在这个新增的 div 里返回不同的图文内容就更好了。

举例，用户直接打开 https://app.pixverse.ai/effect ，后端是能够识别到 url 中的 effect 部分的，那么就需要返回专门为特效写的图文介绍，并且放到 introduction div 里去。

其他页面处理方式相同。

以上是在前端代码不大改的情况下，小小改动，就能够实现 SEO 友好页面的改进建议。

第五点，Canonical 没设置正确，导致出现了重复页面。

关于 Canonical 可以先看哥飞写的《【哥飞SEO教程】再聊 Canonical 标签，用好有好处，用错有坏处，需要小心用》，了解基本用法，然后再去合理设置。

举例来说，别的网站外链指向的三个红框URL，其实规范化的URL都是 https://app.pixverse.ai/，那么就需要把三个 URL 的 Canonical 都设置成 https://app.pixverse.ai/ 。

同样的 /?via=xxx 这类网址，其实也应该把 Canonical 设置为 https://app.pixverse.ai/ 。

第六点，整个页面没有 Headings ，让爬虫抓不住重点。

其实还是因为前端渲染的原因，并且前端开发工程师没有任何SEO概念，所以网页里没有使用任何H1到H6标签。

Headings 是网页的骨架，可以更好的帮助搜索引擎爬虫理解你这个网页的主要内容是什么，所以需要合理使用。

这里哥飞的建议是配合刚才
第四点建议，在不同页面的 introduction div 里写图文内容，并且合理使用 Headings 就好了。

以上就是哥飞给 Pixverse 的简单评测和改进建议，并且考虑到网站已经上线很久了，不宜大改，所以只给了小改建议。

最后总结一下，只要你的品牌够强，强到用户愿意主动搜索你的品牌名称来找到你，那么你不做任何SEO也可以获取到搜索流量。

不过，这里的搜索流量，就只会有品牌词搜索量就是了。

但是砸钱出去之后，想要长期获取流量，还是需要考虑SEO的。
