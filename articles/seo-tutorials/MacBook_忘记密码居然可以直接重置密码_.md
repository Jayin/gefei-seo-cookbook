# MacBook 忘记密码居然可以直接重置密码 

MacBook 忘记密码居然可以直接重置密码？

浪费了一晚上时间，结果靠小红书一个视频就解决了。

有一台之前给同事用的电脑退役后好几个月没人用了，我晚上想着打开用一下。

结果发现我忘记密码了。

又问了所有可能知情人员，回答皆不知。

又找了这个同事入职前后几天我跟所有可能知情人的聊天记录看看有没有提到密码，结果发现毫无线索。

而此时因为我一直在尝试各种可能的密码，每次都需要等一段时间才能继续输入密码，刚等待了3小时可以输入密码，再次输入一个错误密码，结果提示要等待8小时后才能登录。

于是我去微信搜索了“MacBook 忘记密码”，元宝的答案提到可以启动时长按进入恢复模式，然后重装系统，结果又冒出密码输入框。

好在这次可以无限重试，不需要等待时间，我测试了二十几个可能的密码都无解。

我又去小红书搜索了同样的问题，点开了第一个视频，里边提到可以在恢复模式打开终端输入 resetpassword 来重设密码，然后就简单了，重新设置了一个密码，重启后登录进去了。

此时我再回到微信搜索这个问题，发现元宝回答的教程发生了变化，也提到了重置密码。

总算解决问题了，但是我心里的不安全感又来了，这岂不是只要拿到了别人的电脑，那就可以自己改个密码就登录进去了？
