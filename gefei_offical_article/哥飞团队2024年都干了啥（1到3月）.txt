哥飞团队2024年都干了啥（1到3月） 原创 我是哥飞 哥飞 在小说阅读器中沉浸阅读 大家好，我是哥飞。2024年的最后一天，哥飞想用时间线的形式，把2023年12月到2024年12月做过的事情，得到的收获、经验和教训，再捋一遍。不过写着写着发现，发生的事情太多了，一篇写不完，所以会分成3篇来写，这是第一篇。2023年12月：组建团队，初步上手2023年11月22日租好了办公室，做好了组建团队的准备。那时候还是一个建筑面积50平米，实际使用面积35平米左右的小办公室，摆放好桌椅之后，可以坐8个人左右。在京东买了桌子椅子，简单收拾一下，稍微布置了一下，通知了几个要好的朋友们，公司在11月28日正式开业了。也就是开业时，其实整个团队就我一个人。接下来的几天，好多朋友们一一到来，办公室越来越热闹了。11月29日，210 来了，他当时刚好Gap，每天在家附近图书馆学习，了解到哥飞办公室还有空位后，他来从零开始学上站。11月30日，Tim 来了，他办好离职之后，说要来哥飞的办公室占一个工位出海上站。12月1日，我们团队第二位成员涛涛正式加入，开始干活了。12月3日 damo 来了，他是来参加12月9日的哥飞的朋友们线下第一次聚会的，提前一周过来说要在哥飞办公室里交流一下。12月4日，我们团队第三位成员K加入，不过很快一周后我就发现他不适合我们团队，2周后发现还是融入不了，于是在12月20日劝退了，发了半个月加赔偿了半个月的薪资给他，也就是上班2周，他拿到了1个月的薪水。12月9日，哥飞的朋友们第一次线下聚会顺利举行，哥飞在深圳线下聚会的分享 。整个12月，我们注册了9个新域名，8个域名没启用，一个域名做了半成品，因为K被劝退而项目终止。制霸地图类产品每年都会火一次，本质满足的是人们的炫耀心理，当时我想着可以做一个海外版的制霸地图生成器，人们可以定制各种打卡盘点地图，分享出去，让别人可以来标记，生成可分享的图片。想法很好，但是这个产品其实强依赖运营，而且开发起来也有一定的工作量，后来K被劝退后，这个项目就没继续做了。涛涛的主要时间花在打基建上了，把之前我用纯 html 上的网站改成 Next.js 项目，另外花了很多时间在 Readweb.ai ，这是我拍脑袋想出来的需求，最后上线后发现没多少人买单。有一回，我去彪哥那里去取经，我说我们正在做 ReadWeb.ai ，大概讲了一下需求场景，还没说完，彪哥说，好，你不用说了，这个没需求的。我当时头铁，没听他的，继续花时间去开发这个网站了，结果正如彪哥所言的，没多少人用。一整年下来，这个站只有三万七的UV，六万八的PV。其实当时想着可以把很多网页都翻译为别的语言，生成海量页面，不过最终没有去做。后来 .ing 域名可以买了，我注册了 stopwatch.ing ，不过不知道怎么回事，没几天，这个域名被收回去了，注册商退款给我了。网站倒是开发好了，给大家看一下。会买这个域名是因为下面这个网站访问量特别大。后来哥飞还分析过另一个流量没那么大但也很赚钱的网站《【哥飞小课堂】月访问量只有200K，但MRR有 $15k+ 的在线倒计时网站分析》。总结一下，整个12月，就这样过去了，办了一场线下聚会，上线了3个网站，1个是把之前的纯html站改成 next.js 站，并且接入了谷歌登录，Stripe支付。上线了 ReadWeb.ai ，但是没多少访问量。上线了 stopwatch.ing，后来域名被收回去了。2024年1月：与机会擦肩而过1月份时，看 Stripe 的收入排行榜，发现 ElevenLabs 的收入很不错，想做一个AI TTS工具网站。抓取了所有动物单词，一个一个去调接口查 .ai 域名是否被注册，找到了一个单词，是某种动物名称，刚好以声音出名，还可以注册 .ai 域名，于是就选择了这个域名。花了一些时间去开发这个网站，不过到现在一年过去了，还没正式上线，准备2025年上线，所以这个域名暂时不透露了。继续调整 ReadWeb.ai 的大量细节，花了很多时间进去。现在想来，完全就是浪费时间。但是当时身处其中时，就没有这样的感觉，总觉得需要精益求精。然后又尝试修改 ReadWeb.ai 的代码，改成一套通用的代码，我可以基于关键词，快速上线一个网站，这个网站的主要能力是抓取关键词相关的网页，用AI整合，翻译为全球各个国家的语言。代码写好了，但是计划没有实施，因为我觉得这样搞海量页面，是在做垃圾站，没有产生新的内容，对于整个互联网没有增益，所以最终没有上站。修改了12月上线的网站，调整了移动端适配，开始有用户付费了。不过这个关键词搜索量比较小，而且因为我把这个站拿来在社群里当作案例网站讲解，很多人都做了这个关键词，导致我的站的排名下降，最终这个站总共3.3K的访问量，产生了四百多美元的收入。这个站满足的需求是图片转视频，现在回想起来，最大的失误，就是单纯的去蹭了一个模型的名称，而没有去做 Image to Video 等业务需求关键词。从上图可以看到，过去12个月，Image to Video 这个关键词在谷歌趋势的热度翻倍了。我属于摸到了这里的机会，但是没有考虑清楚，导致错失了机会。1月总结，总共注册了6个新域名，但都没上站，既没上新站，又错失机会，后悔莫及。2024年2月：春节和开源整个2月，大部分时间是春节放假，没有啥进展。春节回来了，Sora 惊艳全世界，我们赶紧开了一个开源项目 SoraWebui ，目的是让人人可以快速基于 Sora 的 API 快速上线一个AI视频网站。这个项目拿到了2300+个 Star，当时还是有一定的影响力的，一度拿到了Github趋势榜第三名。推荐一个能让你在 Sora API 发布之前就上线网站接住泼天流量的开源 Sora Web 客户端 SoraWebui 。开源地址：https://github.com/SoraWebui/SoraWebui/配套Fake API项目地址：https://github.com/SoraWebui/FakeSoraAPI/利用这个项目，我们验证了，开源的确是很好的宣传手段，能够吸引别人自发的帮你宣传。尤其是你的开源还是蹭了一些大事件的热度时，如我们这个项目蹭了 Sora 的热度。不过由于 OpenAI 一直捂着 Sora 不放出来，后来反倒是被可灵等一众视频生成模型赶超了。到了2024年12月，Sora发布了，已经没啥水花了。2月29日，Banbri 来了，他在2023年9月上线的两个网站，流量越来越高，收入越来越高之后，就把老板炒了，自己出来做独立开发了。因为哥飞办公室还有工位，他就来深圳上站了。总结一下，2月份没啥大的进展，注册了15个域名，大部分是跟 Sora 相关的，其中 只有 SoraWebui.com 上线了。春节放假占了一半时间，之后立项做开源项目 SoraWebui ，拿到了一定影响力，但是没有产生收入。2024年3月：图片站失败，AI工具站开始赚钱3月2日，BingNi 也来哥飞办公室了。3月6日，注册了 Sticker.Show 域名，要做一个AI贴纸网站。不过这时候的我，对于海量页面的理解还不够深，没有按照精品工具页面的思路去做，而是为每一张图片都生成了一个页面，导致出现了大量低质量页面，很快这个站在4月底被惩罚了。3月10日，Clara 在我们的怂恿下，给网站加上了支付，然后就《1200UV的AI工具站每天200美元收入》。3月12日，用 Sticker.Show 的代码，上线了另一个图片站，不过后续没有去推广。这些海量页面，都需要围绕着用户会搜索的关键词去做高质量页面，不过当时都没有去做。3月13日，哥飞发现一个词很火，不过这是一个别人的产品名称，哥飞手痒注册了一个 .dev 后缀的域名测试了一下，很快就拿到了排名，《哥飞花半天时间做出来的单页网站，五天时间从谷歌获取了28100个点击》。不过很快就没热度了，所以后面没怎么管这个站，也没有去加广告啥的。3月16日，BingNi和Banbri合作，做了一个网站，几天后拿到了$1700美元单日最高充值收入，《哥飞朋友的网站上线第六天用户付费766美元，你没赚钱很可能就是差了执行力》。3月22日，基于 Sticker.Show
